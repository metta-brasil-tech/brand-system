§1 O que é

A identidade visual da Metta é o sistema que traduz a plataforma de marca — inteligência comercial para empresários — em forma. Não é um conjunto de preferências estéticas: é a tradução visual de um posicionamento. Cada escolha de cor, peso tipográfico, grid e espaçamento existe pra reforçar uma mesma promessa: a Metta opera com método, não com improviso.

Isso muda o que esperar do sistema. Ele não é um catálogo de "looks" pra escolher conforme a peça. É um sistema de decisão: dada uma peça nova, o sistema te leva por uma sequência de escolhas justificáveis até o resultado. Quando dois designers diferentes usam o mesmo sistema, as peças saem coerentes — não idênticas, mas reconhecíveis como Metta.

A linguagem é deliberadamente editorial, não publicitária. Onde a maioria das marcas de consultoria usa fotos de aperto de mão, gradiente azul corporativo e CTAs grandes em vermelho, a Metta usa charcoal, amarelo de assinatura, tipografia hierarquizada com peso e espaço em branco generoso. A peça parece um trecho de Bloomberg ou de Monocle — não um anúncio. Esse é o ponto.

§2 Pra que serve

A identidade visual existe pra resolver quatro problemas práticos do negócio.

Autoridade. O empresário que a Metta atende não compra promessa, compra prova. A linguagem editorial sinaliza, antes mesmo do texto ser lido, que ali tem método — porque marcas que operam por método se comunicam assim. Isso reduz o trabalho que a copy precisa fazer pra estabelecer credibilidade.

Recall e coerência. Em mercados saturados, o que faz uma marca ser lembrada não é uma campanha brilhante isolada — é a soma consistente de todos os pontos de contato. O sistema garante que um ad no Instagram, uma proposta comercial, um slide de webinar e um e-mail transacional sejam reconhecíveis como Metta sem ninguém precisar conferir o logo.

Eficiência criativa. Sistema bom é sistema que reduz reinvenção. Quando paleta, tipografia, hierarquia e padrões de composição estão decididos, a equipe de criação para de gastar energia em escolhas pequenas e foca onde importa: na ideia da peça. Cycle time cai, qualidade sobe.

Filtro pra exceções. Toda marca tem casos onde o sistema parece não caber — uma parceria, um evento, uma adaptação cultural. O sistema bem documentado torna a exceção uma decisão consciente, não um acidente. A pergunta deixa de ser "isso parece Metta?" e passa a ser "qual princípio do sistema essa peça precisa quebrar, e por quê?".

§3 Como funciona

O sistema é organizado em três camadas, da mais abstrata pra mais concreta.

Fundamentos. Os átomos da linguagem: paleta de cores (charcoal, neutros e amarelo de assinatura), família tipográfica única em múltiplos pesos, grid, escala de espaçamento, raios de canto. Não são decisões de peça — são as restrições que toda peça herda. Vivem na sub-aba Tokens.

Componentes. As peças reutilizáveis construídas a partir dos fundamentos: cards, botões, badges, blocos de citação, indicadores editoriais, linhas de assinatura. Cada componente resolve um problema recorrente de comunicação. Vivem nas sub-abas Componentes e UI Kit.

Padrões editoriais. O nível mais alto: como compor componentes em peças coerentes com a voz Metta — quando usar o amarelo, quando aplicar símbolo vs. wordmark, como hierarquizar uma proposta comercial vs. um ad de Instagram, como tratar imagem fotográfica. É aqui que o sistema deixa de ser técnico e vira editorial. Vivem no Manual de Marca e no PRD de Identidade Visual.

A regra é: peça nova começa pelo padrão (qual tipo de peça é, qual a função), passa pelos componentes (o que já existe pronto), e só desce até o token quando precisa customizar. Quem trabalha de baixo pra cima — começando pela paleta — geralmente reinventa o que já existe.

§4 Princípios fundadores

Editorial, não publicitário. A Metta se comunica como veículo de inteligência, não como anunciante. Layout com hierarquia tipográfica clara, densidade informacional respeitada, espaço em branco generoso. Quando algo grita visualmente, é porque a mensagem exige — não porque a peça precisa "chamar atenção".

Charcoal como base, amarelo como sotaque. A paleta principal é cinza-grafite, off-white e neutros quentes. O amarelo é assinatura: aparece em momentos pontuais — destaque de dado, citação, indicador editorial — nunca como fundo dominante e nunca em decoração. O amarelo Metta vale porque é raro.

Uma família tipográfica, muitos pesos. Toda a hierarquia — display, título, corpo, caption — é construída com uma única família, variando peso, tamanho e tracking. Isso garante coerência sem precisar de mais de uma fonte e reforça o tom editorial. Display tem presença forte; corpo tem clareza absoluta.

Geometria precisa. Cada elemento tem âncora no grid. Cantos arredondados consistentes, alinhamentos rigorosos, nada flutuante ou solto. A precisão visual sinaliza precisão metodológica — é parte da prova.

Imagem é editorial, nunca stock. Quando há fotografia, ela é documental: luz natural, mood analítico, pessoas em decisão e não em pose. Stock genérico de "executivo sorrindo apertando mão" é proibido — fere o posicionamento antes de qualquer texto ser lido.

Decoração sem função é proibida. Se um elemento visual existe, ele resolve um problema de comunicação. Ornamento gratuito, ícone só pra preencher, gradiente só pra "ficar mais bonito" — fora. O sistema é minimalista por método, não por estética.

§5 Quando consultar este sistema

  • Criar peça nova. Antes de abrir o Figma, passe por aqui pra entender qual padrão editorial cabe e quais componentes já existem prontos.
  • Validar entrega de fornecedor. Use os princípios fundadores como filtro institucional antes de descer pra checagem técnica de tokens e componentes.
  • Treinar designer ou redator. Esta página é o onboarding. As sub-abas técnicas são manual de operação.
  • Decidir sobre exceção. Quando uma peça parece não caber no sistema, este doc é o ponto de partida pra justificar a quebra — ou descobrir que ela não é necessária.
  • Apresentar a marca pra cliente, parceiro ou candidato. Resumo institucional pronto, sem precisar mergulhar em hex codes.
  • Auditar coerência cross-channel. Pega 5 peças de canais diferentes, abre este doc ao lado e checa se a marca está soando como uma só.

§6 Onde está cada coisa

  • PRD de Identidade Visual — especificação completa, fonte canônica de toda decisão técnica.
  • Tokens — paleta, tipografia, escala de espaçamento, raios, tudo o que é variável fundacional.
  • Componentes — peças atômicas reutilizáveis (cards, botões, badges, blocos editoriais).
  • UI Kit — padrões compostos, exemplos de aplicação, peças de referência.
  • Logos — variações de logo, regras de uso, marcas d'água, casos especiais.
  • DS Técnico — referência de implementação no Design System v2 (Figma + tokens em código).
  • Manual de Marca (na aba Marca) — princípios de aplicação editorial em prosa, complementar a este resumo.
