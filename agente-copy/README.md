# Copy Agent — Metta Brasil

Agente de IA especializado em copywriting para conteúdo social da marca Metta Brasil. Em vez de gerar texto direto, o agente entrevista antes de escrever — captura objetivo, ICP, ângulo, eixo emocional (dor/desejo/necessidade) e CTA — e só então produz a peça, sempre embebida do ICP, da linguagem real do cliente (EMIC) e do tom de voz institucional da marca.

Cobre 6 tipos de copy, cada um com sua própria lógica de entrevista e formatação: carrossel, post único, descrição de post, stories, reels e criativos. Toda peça passa por validação (checagem de ICP, gramática e tom de voz) antes da entrega, com nota da Skill de Validação anexada.

Stack: Python + API da Anthropic (Sonnet para tarefas estruturais, Opus para julgamento de copy), sem orquestração no-code. Base de conhecimento de marca versionada e lida a cada execução.

Escopo atual: marca Metta Brasil. Suporte a marcas adicionais está previsto na arquitetura, mas fora deste escopo inicial.
