# 1. Princípio de organização

A base não é um amontoado de documentos — é uma biblioteca em camadas. Há uma regra de precedência e uma separação clara entre as duas marcas (Metta institucional e Tiago Alves pessoal).

| **Regras de precedência (já definidas nos próprios documentos)** Glossário prevalece sobre qualquer outra fonte em caso de conflito de termo proprietário. Protocolo M.E.T.T.A. V9 é a fonte canônica da metodologia; divergências em outros docs são descartadas. Em provas/números: a transcrição do depoimento prevalece sobre o número institucional. Tom de voz é arquitetura, não catálogo de frases: reproduz a mecânica, não copia bordão. |

# 4. Separação por marca

Os dois agentes precisam saber, a cada execução, de qual marca estão tratando. A regra geral dos próprios documentos:

| **Tiago vende visão de mundo. Metta vende implementação.** Tiago é quem viveu o problema (mito pessoal, autoridade humana, voz pessoal). Metta é o sistema que resolve (categoria nova, movimento, voz institucional). Nunca misturar as vozes na mesma peça nem no mesmo bloco do calendário. |
| --- |

| **Eixo** | **Marca Tiago Alves** | **Marca Metta** |
| --- | --- | --- |
| Voz | tom-de-voz-tiago | tom-de-voz-metta |
| Narrativa | mito-fundador-tiago | mito-fundador-metta |
| Registro | Pessoal, vivência, par com o ouvinte | Institucional, autoridade técnica, movimento |

# 5. Como entra no prompt de cada agente

## 5.1 Agente de Copy

Montagem do contexto na hora de escrever a peça:

- Marca selecionada → carrega o par de voz + narrativa correspondente

- ICP (estratégico + secundário do segmento) + EMIC → linguagem e dor

- Glossário → termos proprietários corretos

- Skill de Copy do formato → estrutura e validação com nota

- Banco de vencedores → referência de performance / variações

## 5.2 Agente Estrategista

Montagem do contexto na hora de planejar o período:

- Marca selecionada → posicionamento + Código de Conteúdo + pilares

- ICP + oferta → objetivo de negócio e fase de conversão/oferta

- Skill de Estratégia → regras de fases e cadência

- Tendências (busca ativa via código) + concorrentes → contexto de mercado do período

- Provas + mito fundador → matéria-prima da fase de autoridade
