# 1. O que é o Agente Copy

O Agente Copy é o copywriter especialista do sistema. Foco exclusivo em copy: ele não desenha peça nem planeja período — produz a palavra escrita, sempre embebido do ICP, da linguagem do cliente (EMIC) e do tom de voz da marca.

Segundo a definição do Tiago: a IA precisa funcionar como um copywriter especialista, que pensa junto com o usuário, reduz retrabalho e economiza tokens fazendo as perguntas certas antes de produzir.

| **Fluxo essencial do Copy** Usuário traz uma ideia ou material → Copy identifica o tipo de copy → entrevista (perguntas próprias do tipo) → escreve embebido de ICP + EMIC + tom de voz → avalia a peça contra o ICP → revisa gramática, fluência e tom → valida pela skill (nota) → passa por um segundo agente avaliador → entrega peça + variações de hook. |
| --- |

# 2. Foco exclusivo em copy

O Tiago foi direto no WhatsApp de 29/06: “o foco é só copy”. Este documento trata apenas da palavra escrita. A peça visual (design, imagem, diagramação) é responsabilidade da Camada Designer, fora do escopo deste agente. O Copy entrega o texto final por tipo; o que vira arte é etapa seguinte.

A entrada do Copy é uma ideia ou um material trazido pelo usuário. O agente não planeja o período nem decide o calendário — recebe o que produzir e produz. Tudo neste documento descreve apenas a produção da copy.

# 3. Tipos de copy — cada um com suas perguntas

O Tiago foi explícito: cada formato tem características muito diferentes e deve ser tratado de forma independente. Os tipos abaixo estão no mesmo nível — a IA identifica qual é antes de escrever e faz as perguntas próprias daquele tipo.

## 3.1 Carrossel

- Dois fluxos de entrada: (a) apenas uma ideia → a IA desenvolve o carrossel inteiro; (b) um texto bruto → a IA transforma em carrossel.

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| É só uma ideia ou um texto bruto para transformar? | Define o fluxo de produção |
| Qual ângulo? (A / B / C sugeridos) | Evita retrabalho antes de escrever |
| Dor, desejo ou necessidade — e qual? | Define o eixo emocional |
| Existe CTA específico ao final? | Define o fechamento |
| Quanto tempo de leitura? (30s / 1min / 2min) | Dimensiona o tamanho da copy |

## 3.2 Post único (estático)

- Imagem única, não-carrossel. Pode ser frase chamariz, frase de autor ou texto mais longo no feed.

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| Frase chamariz, frase de autor ou texto longo? | Define o subtipo do estático |
| Qual ângulo e qual eixo (dor/desejo/necessidade)? | Direciona a mensagem |
| Há assinatura / @ / autoria a exibir? | Ajusta o fecho do texto |

## 3.3 Descrição de post

O Tiago destacou: no post estático, a descrição é o principal elemento de copy — “a cópia, ao invés de estar no carrossel, é o descritivo”. Todo post tem descrição, mas aqui ela carrega a mensagem e por isso é um tipo próprio.

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| A descrição acompanha qual peça? (estático, carrossel, reels) | Calibra extensão e função da legenda |
| A descrição é o chamariz ou complementa o visual? | Define o peso da copy na descrição |
| Qual CTA fecha a descrição? | Direciona para a ação |

## 3.4 Stories

Story não é um formato único. A IA gera o tipo certo conforme a estratégia: enquete, caixa de perguntas, sequência e levantamento de dor (social selling).

| **Sequência dor → desejo → necessidade (social selling)** O Tiago pediu explicitamente a mecânica de sequência: stories encadeados que ativam dor, depois desejo, depois necessidade, e então geram comentários ou abrem caixa de perguntas. A IA não gera só stories soltos — monta a sequência com a progressão emocional, conforme a estratégia. |
| --- |

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| Story único ou sequência? | Define se ativa a mecânica de progressão |
| Qual tipo? (enquete / caixinha / sequência / levantamento de dor) | Seleciona a estrutura |
| Se sequência: qual progressão? (dor → desejo → necessidade) | Define o eixo de cada story |
| Gera comentário ou abre caixa de pergunta ao final? | Define o gancho de social selling |

## 3.5 Reels

Vários subtipos, cada um com características próprias. Os subtipos confirmados pelo Tiago no WhatsApp: longo de conteúdo, curto, e respondendo caixinha. As perguntas de copy são quase as mesmas do carrossel (texto pronto ou ideia), somadas ao tipo e à duração.

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| Qual subtipo? (longo de conteúdo / curto / respondendo caixinha) | Define a estrutura do roteiro |
| É só uma ideia ou um texto bruto? | Define o fluxo de produção |
| Qual a duração-alvo do vídeo? | Dimensiona o roteiro |
| Começa com gancho/pergunta? | Define a abertura |
| Se respondendo caixinha: qual a pergunta de origem? | Conecta o reels ao story anterior |

## 3.6 Criativos (estáticos ou em vídeo)

O Tiago tratou “criativos” como categoria própria: os diversos criativos que a Metta usa, sejam estáticos ou em vídeo. Aqui entra a copy de criativo de tráfego/anúncio, distinta do conteúdo orgânico de feed e reels, e conectada ao banco de vencedores (seção 6).

**Perguntas próprias:**

| **A IA pergunta** | **Para quê** |
| --- | --- |
| Criativo estático ou em vídeo? | Define o formato da copy |
| É criativo novo ou variação de um vencedor? | Aciona o banco de vencedores (seção 6) |
| Qual objetivo? (lead, clique, agendamento) | Direciona o CTA do criativo |
| Qual dor/desejo/necessidade ataca? | Define o ângulo de conversão |

# 4. Adaptação por plataforma (IG e LinkedIn)

Do briefing de escopo (seções 3.2 e 5.4): a copy não é a mesma entre plataformas. O Copy escreve para Instagram (foco principal) e adapta para LinkedIn — não copy-paste, mas reescrita com o tom apropriado da plataforma. Stories e LinkedIn têm regras distintas de IG.

| **Plataforma** | **Tratamento da copy** |
| --- | --- |
| Instagram | Foco principal. Todos os tipos da seção 3. |
| LinkedIn | Adaptação a partir da copy de IG, com tom apropriado — reescrita, não cópia. Carrossel vira PDF; descrição mais densa. |
| Stories | Regras próprias de ritmo e fragmentação; tratado na seção 3.4. |

| **Decisão registrada — LinkedIn no MVP** O WhatsApp do Tiago de 29/06 foca na taxonomia de formatos do Instagram e não cita LinkedIn. O briefing de 28/04 inclui LinkedIn na fase 1. Decisão: LinkedIn está incluído neste documento, conforme o briefing. Recomenda-se confirmar com o Tiago na validação, já que a lista mais recente dele priorizou os formatos de IG. |

# 5. A entrevista antes de escrever

Ponto mais importante para o Tiago: a IA não sai escrevendo. Primeiro pergunta. Isso reduz subjetividade, evita retrabalho e economiza tokens. As perguntas-base abaixo seguem exatamente a lista do PMO de 11/06; cada tipo de copy (seção 3) acrescenta as suas próprias.

| **A IA pergunta (lista do PMO)** | **Para quê** |
| --- | --- |
| Qual é o objetivo? | Direciona toda a copy |
| Qual o ICP? | Embebe a peça no público certo |
| Qual ângulo deseja seguir? | Evita retrabalho antes de escrever |
| Trabalhar dor? | Define o eixo emocional |
| Trabalhar desejo? | Define o eixo emocional |
| Trabalhar necessidade? | Define o eixo emocional |
| Existe CTA específico? | Define o fechamento |
| Qual formato? | Seleciona o tipo e suas perguntas próprias |
| Qual tempo de leitura? | Dimensiona a copy de carrossel / texto |
| Qual tempo do vídeo? | Dimensiona o roteiro de reels / criativo em vídeo |

| **Adição ao núcleo do PMO — pergunta de marca** Acrescentamos uma pergunta que não está na lista do PMO: “Qual marca? (Metta ou Tiago Alves)”. Ela não veio do Tiago — é uma adição nossa para travar a regra de separação inviolável das vozes antes de escrever. Registrada aqui como decisão consciente, para o Tiago aprovar ou retirar. |

# 6. Base que alimenta o Copy

O Copy precisa estar embebido — não apenas conhecer superficialmente. A base, na ordem que o Tiago exigiu:

| **Fonte** | **Estado** | **Função** |
| --- | --- | --- |
| ICP (Mentoria + Varejo + Serviços) | Em mãos | Define o público de cada peça |
| Pesquisa EMIC (linguagem do cliente) | v1 consolidada das fontes | Termos reais do mercado; ampliada com pesquisa de campo |
| Tom de voz Metta / Tom de voz Tiago | Em mãos | Separação inviolável das vozes |
| Avatar, posicionamento, oferta, provas | Em mãos | Contexto de mensagem e mecanismo |
| Glossário | Em mãos | Prevalece em conflito de termo proprietário |
| Skill de Copy | Em mãos (Metta) | Regras de copy; expandir para a marca Tiago |

| **Ponto de atenção — EMIC** A EMIC está em v1 consolidada das fontes que temos, e já alimenta o Copy. Não é a pesquisa de campo definitiva — esta amplia a v1 quando vier. Apresentar como v1, nunca como definitiva. |
| --- |

# 7. Escolha de ângulo

Em vez de escrever direto, a IA sugere caminhos e o usuário decide. A partir de uma ideia, a IA propõe Ângulo A, B ou C; o usuário escolhe; só então a IA escreve. Isso reduz retrabalho.

# 8. Transformação de material rico

A IA aceita uploads — aula, ebook, PDF, material rico — e deriva automaticamente múltiplos tipos (reels, stories, carrosséis, posts, descrições) a partir do mesmo tema.

# 9. Banco de vencedores e variações

A partir de um criativo que comprovadamente performou, a IA cria derivações (versão A, B, C) mantendo os elementos responsáveis pela performance — independente do tipo. O marketing alimenta o sistema com os criativos vencedores (mais leads qualificados, melhor CTR), que entram como benchmark permanente (lógica comparável ao NotebookLM).

# 10. Validação: skill + segundo agente avaliador

A qualidade da peça passa por duas checagens distintas antes da entrega:

| **Camada** | **O que faz** | **Origem do requisito** |
| --- | --- | --- |
| Avaliação contra o ICP | A peça pronta é avaliada: “faz sentido para esse público?” antes de seguir | Briefing 3.2 |
| Revisão de gramática, fluência e tom | Checa correção, fluência e aderência ao tom de voz da marca | Briefing 3.2 |
| Skill de Validação | Retorna uma nota; a IA entrega a nota junto com a peça | PMO / WhatsApp Tiago |
| Segundo agente avaliador | Auto-crítica: um segundo agente revisa a peça antes da entrega final | Briefing 3.2 |

| **Decisão registrada — segundo agente vs. skill** O briefing pede um segundo agente avaliador (auto-crítica). O PMO/WhatsApp do Tiago fala da nota da skill existente. São coisas distintas e ambas entram: a skill dá a nota; o segundo agente faz a crítica qualitativa antes da entrega. Confirmar com o Tiago se ele quer os dois passos ou apenas a skill. |
| --- |

Sobre a Skill de Validação: ela já existe e precisa ser localizada e integrada ao fluxo antes do MVP.

# 11. Entregáveis do Copy

- Copy final pronta para publicação: hook + corpo + CTA.

- Mínimo de 3 variações de hook por peça.

- Indicação de pilar de conteúdo e ICP-alvo.

- Nota da Skill de Validação anexada à peça.

- Parecer do segundo agente avaliador.

- Versão adaptada para LinkedIn quando a peça for de plataforma cruzada.

- Variações de criativos vencedores quando solicitado.

# 12. Arquitetura técnica

- Reasoning → Claude via API: Sonnet para tarefas estruturais (entrevista, roteamento, formatação); Opus para julgamento de copy (tom, ângulo, calibração de voz). Nunca Haiku — correção registrada no Documento Mestre v2.0; esta seção estava desatualizada em relação a essa decisão.

- Base de conhecimento → versionada no GitHub, lida no início de cada ciclo. Sem RAG/embeddings.

- Interface → brandsystem (a confirmar como local de saída/download das peças).

- Validação → Skill de Validação + segundo agente avaliador no fluxo, retornando nota e parecer.

- Human-in-the-loop → nada vai ao ar sem aprovação humana (Alisson aprova publicação).

# 14. Critérios de aceitação (Copy v1)

- A IA entrevista antes de escrever, com perguntas próprias de cada tipo.

- Trata cada tipo de copy de forma independente: carrossel, post único, descrição de post, stories (com sequência dor→desejo→necessidade), reels (longo/curto/caixinha), criativos (estático/vídeo).

- Adapta a copy entre Instagram e LinkedIn, com tom próprio de cada plataforma.

- Escreve embebido de ICP, EMIC e tom de voz, sem misturar as vozes das marcas.

- Sugere ângulos A/B/C antes de escrever.

- Avalia a peça contra o ICP e revisa gramática, fluência e tom.

- Valida pela skill (nota) e passa pelo segundo agente avaliador.

- Gera no mínimo 3 variações de hook por peça.

- Está rodando e qualquer pessoa do time consegue usar (definição de entrega do Tiago).
